# ♟️ Web Damas

Jogo de **Damas online multiplayer** desenvolvido com arquitetura **client/server**, permitindo partidas em tempo real diretamente pelo navegador.

🔗 Demo: https://web-damas.vercel.app  
📦 Repositório: https://github.com/mendesjar/web-damas  

---

## 📖 Sobre o projeto

O **Web Damas** é uma aplicação web que implementa o clássico jogo de damas com suporte a partidas online entre jogadores.

O projeto foi criado com foco em:

- Comunicação em tempo real
- Arquitetura separada (frontend + backend)
- Experiência simples e responsiva
- Prática de WebSockets e TypeScript

---

## 🧠 Funcionalidades

- ♟️ Tabuleiro de damas funcional
- 👥 Multiplayer em tempo real
- 🔄 Sincronização automática do estado do jogo
- 🏁 Regras básicas de damas implementadas
- 🌐 Interface web acessível pelo navegador
- ⚡ Comunicação cliente-servidor

---

## 🏗️ Arquitetura do projeto

O repositório está dividido em duas partes principais:

### 🔹 Client
Responsável por:
- Interface do jogo
- Renderização do tabuleiro
- Interação do jogador
- Comunicação com o servidor

### 🔹 Server
Responsável por:
- Gerenciamento de salas
- Sincronização das partidas
- Regras e estado do jogo
- Comunicação em tempo real
